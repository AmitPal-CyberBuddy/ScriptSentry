Run it locally — it's free & private

You're viewing the hosted interface. For privacy, ScriptSentry never sends your code to a cloud. Start the local engine, then this page connects to it automatically. Pick the easiest option:

Download one file. On first run it fetches the engine from the official GitHub repo, installs dependencies, and starts — no clone needed.

  1. Download the launcher above (or copy it straight from GitHub).
  2. Run it: python3 scriptsentry.py --port 8000 — the first run downloads the engine.
  3. Paste the pairing token it prints into the field below.
# downloads & starts the engine on first run
python3 scriptsentry.py --port 8000
  1. Get the project: clone or download ScriptSentry.
  2. Open a terminal inside the project folder.
  3. Install deps: pip install -r requirements.txt
  4. Start the server: python3 server.py --port 8000
  5. Keep this page open and press Retry connection.
git clone https://github.com/AmitPal-CyberBuddy/ScriptSentry.git
cd ScriptSentry
pip install -r requirements.txt
python3 server.py --port 8000

⚖️ Authorized testing only. Only scan systems you own or have explicit written permission to test. You are responsible for lawful use.

⚠️ If you change the port, update webui/config.js to the same port. The engine prints a pairing token at startup; it stays in this tab only.

Pair the engine

The token is printed in your terminal when the engine starts. It is kept in this browser tab only — never in the URL, never in a report.
