02 — Workflow

How It Works

Three ways in, one evidence-driven pipeline, and a dashboard built for triage instead of noise.

  1. 01

    Give It Code

    Paste JavaScript, drag & drop your bundle files, or scan a URL. The engine crawls imports and bundler chunk maps to find the real script graph.

  2. 02

    It Profiles Behavior

    Every script gets a behavior profile: first/third-party attribution, sensitive reads, DOM and network writes, browser APIs and a 0–100 script risk score.

  3. 03

    Follow the Data

    Taint analysis traces source→sink paths, ranks them by evidence strength, and states the limits of every conclusion. If the app ships source maps, the analysis reads your original source instead of the minified blob.

  4. 04

    Triage, Then Export

    Mark findings open, needs review, confirmed, false positive or informational, then export HTML, TXT, CSV, SARIF or raw JSON — and hand the discovered API surface to your proxy as an OpenAPI map.

03 — Trustworthiness

Built to Avoid Crying Wolf

ScriptSentry keeps three questions separate — most scanners blur them together.

QuestionAnswer
How bad would it be if real? Severity — Info → Critical
How certain is the evidence? Confidence — low → high → confirmed
What's the analyst state? Open · Needs review · Confirmed · False positive · Informational

A regex hit is not treated as proof. A static source→sink path is reported as high confidence but stays Open — encoding, framework sanitizers or unreachable code may still neutralize it. Confirmed is reserved for deterministic proof or a demonstrated runtime effect.

04 — Requirements

Run Your Own Engine

The page you are reading is only the interface. Start the engine on your machine once, and this dashboard connects to it automatically — nothing is uploaded anywhere.

One File Is Enough

Download a single launcher. On first run it fetches the engine, installs dependencies and starts — no clone required.

  1. Download the launcher above (or copy it straight from GitHub).
  2. Run it: python3 scriptsentry.py --port 8000 — the first run downloads the engine.
  3. Copy the pairing token it prints, then paste it into the setup dialog.
python3 scriptsentry.py --port 8000
Prefer the full repo? (git clone)
  1. Clone ScriptSentry and open a terminal inside it.
  2. Install deps: pip install -r requirements.txt
  3. Start the server: python3 server.py --port 8000
  4. Keep this page open and press Retry Connection in the setup dialog.
git clone https://github.com/AmitPal-CyberBuddy/ScriptSentry.git
cd ScriptSentry
pip install -r requirements.txt
python3 server.py --port 8000

⚠️ If you change the port, update webui/config.js to the same port.

Prefer a package install? (pip / pipx / Docker)
  1. Clone the repo, then install it: pip install . (or pipx install .).
  2. Start the dashboard: scriptsentry-server --port 8000 — same pairing-token flow.
  3. Or scan from the CLI: scriptsentry --help — every report format, no web UI needed.
git clone https://github.com/AmitPal-CyberBuddy/ScriptSentry.git
cd ScriptSentry
pip install .
scriptsentry-server --port 8000

🐳 Docker (Chromium for runtime evidence preinstalled): docker build -t scriptsentry . && docker run --rm -p 8000:8000 scriptsentry
