Run it locally — it's free & private

You're viewing the hosted interface. For privacy, ScriptSentry never sends your code to a cloud. Start the local engine, then this page will connect to it automatically.

  1. Get the project: clone or download ScriptSentry.
  2. Open a terminal inside the project folder.
  3. Install deps: pip install -r requirements.txt
  4. Start the server: python3 server.py --port 8000
  5. Keep this page open and press Retry connection (connected via 127.0.0.1).
cd ScriptSentry
pip install -r requirements.txt
python3 server.py --port 8000

⚠️ If you change the port, update webui/config.js to the same port.
